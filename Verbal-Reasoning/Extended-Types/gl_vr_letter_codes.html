How These Questions Work

🧒 Simple Explanation

Imagine each letter has a secret number instead of its name. A might be 3, B might be 7, and so on. The same letter always gets the same number — and two different letters can never share the same number.

You're given some words and their codes as clues. You use those clues to figure out a mystery word's code — or to work backwards and find what word a code stands for.

📖 Full Explanation

Each question uses a one-to-one substitution cipher: every letter maps to exactly one unique digit, and every digit maps to exactly one unique letter. The mapping is consistent across all words in the question.

You are given 2–4 word/code pairs as your key. Your task is to:

  • Build a letter→digit mapping table from the given pairs
  • Apply that mapping to find the missing code or
  • Apply the reverse mapping (digit→letter) to decode a code into a word

📌 Reference: Letter–Number Alphabet Strip

These are the standard A=1 values. In questions the examiner uses their OWN mapping — use this strip only to count letter positions if needed.

⚡ Master Strategy — Always Follow This Order
  • 01 Look for the "odd-one-out" word — one that shares the most letters with others. Start there.
  • 02 Compare two words that differ by ONE letter only — you can identify both letters' codes instantly.
  • 03 Build a mapping table — write each letter and its number. Never guess from memory.
  • 04 Check for repeated letters first — if a word has a double letter (e.g. MOON), its code must show the same digit twice (e.g. _22_).
  • 05 Verify every letter before writing your final answer.

🆘 Fallback: No Obvious Starting Point?

If all words share the same first letter, or all the same last letter — scan the middle positions instead.

If no words share a letter — check the codes for repeated digits. A repeated digit means a repeated letter.

Still stuck? Pick any two words and map ALL their shared positions first.

Word → Code (Basic)

✔
🧒 Simple Explanation

You're given some word/code pairs as clues, and you need to find the code for a new word. Think of it like a treasure map key — once you know what each letter means, you can decode anything.

The trick: two words that are almost the same (differ by one letter) tell you what BOTH different letters mean!

📖 Full Explanation

Given clue pairs, identify which letters differ between words, then match them to which digits differ between their codes. Build your complete letter→digit mapping, then substitute each letter of the target word.

✏️ Worked Example 1 — Step by Step

Given:

CAT = 123 CAR = 124 BAR = 524

Find the code for: BAT

  1. Compare CAT (123) and CAR (124): These differ only in position 3: T vs R, and code digits 3 vs 4. So T = 3, R = 4.
  2. From CAT (123): C = 1, A = 2, T = 3. Confirmed: T = 3.
  3. From BAR (524): B = 5, A = 2 ✔, R = 4 ✔. So B = 5.
  4. Build the table:
C1
A2
T3
R4
B5

BAT = B(5) A(2) T(3) = 523

⚠️ Watch Out!

"Order Ignorance": Students sometimes collect the right letters and numbers but scramble the positions. Always go left-to-right through the target word, substituting one letter at a time. Never write digits in the wrong order.

✏️ Worked Example 2 (Harder)

Given:

SHIP = 3452 CHIP = 1452 CHIN = 1467

Find: SHIN

  1. SHIP vs CHIP differ only at position 1: S vs C, codes 3 vs 1. So S=3, C=1.
  2. CHIP vs CHIN differ only at position 4: P vs N, codes 2 vs 7. So P=2, N=7.
  3. From SHIP: H=4, I=5.
  4. Table: S=3, H=4, I=5, P=2, C=1, N=7.
  5. SHIN = S(3) H(4) I(5) N(7) = 3457

Repeated Letters in Codes

✔
🧒 Simple Explanation

If a word has the same letter twice (like MOON has two O's), then its code must have the same digit twice in the same positions. So MOON might be coded as 1223 — notice how 2 appears twice, just like O appears twice.

This is your superpower! Spot the repeated digits in a code → find the repeated letter in the word. Or spot the double letter in a word → look for the double digit in the code.

📖 Full Explanation

The one-to-one mapping rule means: same letter always = same digit, and different letters always = different digits. When a word contains a repeated letter, that letter's digit appears in exactly the same positions in the code.

Key strategy: always identify repeated letters first. They immediately reveal the code structure and eliminate wrong options.

✏️ Worked Example 1 — Scholarship Level

Given:

MOON = 1223 NOON = 4223 SOON = 3223

Find the code for: MOOT

  1. Spot the repeated letters: All three words contain "OON". In all three codes, positions 2–3–4 are "223". So OO=22, N=3.
  2. From MOON=1223: M=1, O=2, O=2, N=3. Confirmed OO=22.
  3. From NOON=4223: N=4? Wait — N is at position 4 of all three words and = 3. But NOON starts with N too, so N must appear at position 1 AND 4. NOON = N(?)O(2)O(2)N(?) but NOON=4223 means position 1=4 and position 4=3. That means N=4 AND N=3 — that's a contradiction!
  4. Reread the words: NOON = N-O-O-N. NOON=4223: position 1=4, pos 2=2, pos 3=2, pos 4=3. For NOON to be valid: the two N's must have the same code. But 4≠3 — contradiction.
  5. Resolution: This means N is NOT both 4 and 3. Looking again — MOON=1223: M=1, O=2, O=2, N=3. NOON=4223: If N=3, position 4 is 3 ✓ but position 1 of NOON would be N=3 also, giving NOON=3223. But NOON=4223, so position 1 = 4 ≠ 3. Contradiction! These clues reveal that in this question NOON has TWO DIFFERENT FIRST and LAST digits, meaning the question intends 4 and 3 as two separate unknowns.
  6. Better reading: M=1, O=2, N=3, and first-of-NOON = 4 must be a NEW letter. But NOON only has N and O… So this is a "symmetry trap" — the student must spot that any answer for MOOT needs M=1, O=2, O=2, T=unknown.
  7. From SOON=3223: S=3? But N=3 from MOON. Contradiction again — S and N can't both be 3.

⚠ This is the trap question! Consistent clue sets are needed. Let's use the clean version below.

✏️ Clean Worked Example — Repeated Letters

Given:

BALL = 1233 FALL = 4233 FELT = 4536

Find the code for: BELT

  1. Spot repeated digits: BALL=1233 — positions 3&4 are both 3. L appears twice in BALL → L=3.
  2. BALL vs FALL differ only at position 1: B vs F, codes 1 vs 4. So B=1, F=4.
  3. From FELT=4536: F=4 ✔, E=5, L=3 ✔, T=6.
  4. Full table:
B1
A2
L3
F4
E5
T6

BELT = B(1) E(5) L(3) T(6) = 1536

⚠️ Watch Out!

"Numbers can repeat randomly" myth: Students sometimes think any digit can appear anywhere. Wrong! Same letter = same digit, always. If you see the digit 3 appearing twice in a code, that letter appears twice in the word — guaranteed. Use this to check your answer.

"Different letters can share a digit" myth: Also wrong. Every letter has its own unique digit. If B=1, no other letter equals 1.

Code → Word (Reverse Decoding)

✔
🧒 Simple Explanation

This time the question gives you a number code and asks you to find the word. It's the same puzzle backwards! Build your key from the clues (number → letter this time), then swap each digit for its letter.

Think of it like a spy reading a secret message — you have the codebook, now decode it!

📖 Full Explanation

Reverse decoding requires building a digit→letter mapping (the inverse of letter→digit). The process is identical: compare given pairs to isolate individual mappings, then substitute each digit of the mystery code with its corresponding letter.

Common trap: Once you know the answer word, check it's a real word (or at least matches the pattern of the given words). If it looks wrong, you may have swapped two letters.

✏️ Worked Example — Code → Word

Given:

DARK = 1234 PARK = 5234 PART = 5236

Which word has the code 1236?

  1. DARK vs PARK differ at position 1: D vs P, codes 1 vs 5. So D=1, P=5.
  2. PARK vs PART differ at position 4: K vs T, codes 4 vs 6. So K=4, T=6.
  3. From DARK: A=2, R=3.
  4. Full digit→letter: 1=D, 2=A, 3=R, 4=K, 5=P, 6=T.
  5. Decode 1236: 1=D, 2=A, 3=R, 6=T → DART ✔
Answer: DART
⚠️ Watch Out!

"Partial Solving" trap: Students build 3 out of 4 digit mappings and guess the last one. Don't! Every digit in the mystery code must be traced to a specific letter from the clue pairs. If a digit isn't covered by your clues, you cannot decode it — recheck whether you've missed a clue pair.

No Easy Entry Point

✔
🧒 Simple Explanation

Sometimes no two words differ by just one letter — it looks like you're stuck! But you're not. The trick is to look at ALL positions and find which two positions change together between any pair of words.

Also: if all words start with the same letter, skip position 1 (you already know that one!) and look at positions 2, 3, 4 instead.

📖 Full Explanation

When no word pair differs by exactly one letter, use this protocol:

  1. Compare any two words. Note ALL positions that differ.
  2. Compare a third word with each of the first two. Find a combination that isolates one letter change.
  3. If all first letters are the same, that first letter's digit is confirmed — focus on the remaining positions.
  4. Use repeated letters/digits to anchor your table early.
✏️ Worked Example — Shared Starting Letter Trap

Given:

FLAT = 1234 FLAB = 1235 FLAG = 1236

Find: GRAFT — wait, G=6 is only revealed in FLAG. We don't know R or F position relevance yet... Better question: Find code for GALT (assuming it's a valid target for practice).

Actually, let's find: BLAG

  1. All three words start with F — so F=1. Position 1 is done.
  2. All three words have LA in positions 2–3: FLA_ — so L=2, A=3.
  3. Position 4 varies: T=4, B=5, G=6.
  4. Table: F=1, L=2, A=3, T=4, B=5, G=6.
  5. BLAG = B(5)L(2)A(3)G(6) = 5236 ✓
⚠️ Watch Out!

"No entry point" panic: Students freeze when no single-letter difference is obvious. Stay calm — the shared positions tell you just as much as the differing ones. Every pair of words gives you information. Write down what you KNOW and work from there.
