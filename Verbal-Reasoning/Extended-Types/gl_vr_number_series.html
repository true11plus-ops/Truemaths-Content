How These Questions Work

✔
🧒 Simple Explanation

You get two pairs of numbers (like two clues), and they both follow the same secret rule. Your job is to figure out what the rule is, then use it to find the missing number in a third pair.

Think of it like this: imagine a machine. You put a number in one end, and it spits a different number out the other end. The machine does the same thing every time. Once you figure out what the machine does, you can answer the question!

📖 Full Explanation

Each question presents two complete number pairs and one incomplete pair:

[a → b] [c → d] [e → ?]

The relationship between the left number and the right number is identical in all three pairs. The relationship may be a single operation (×, +, −, ²) or a combination of operations. Your task is to identify the rule, verify it on both given pairs, then apply it to find the missing value.

In harder questions, the missing number may appear on the left — requiring you to work backwards.

⚡ Speed Strategy — Check in This Order

  • 01 Try × first. Does b = a × something clean? (e.g. ×2, ×3, ×5)
  • 02 If not, try + or −. Does b = a + something?
  • 03 If numbers jump a lot, try squaring. Is b = a²? Or a² ± something?
  • 04 Then try combos: × then +, or × then −
  • 05 If not clear in 5 seconds — skip, come back later
  • 06 ALWAYS verify on the second pair before writing your answer

🧠 Quick Thinking Method

Step 1: "What did they DO to the first number?"

Step 2: "Try it on the second pair. Still works? Good."

Step 3: "Now apply that same thing to find the missing number."

Multiplication Rules

✔
🧒 Simple Explanation

Sometimes the machine just multiplies your number. So if you put in 3 and get out 9, the machine must be doing ×3. Easy! Always try multiplication first because it's the most common rule in these questions.

The trick? Check it works for both pairs before you use it.

📖 Full Explanation

A multiplicative rule takes the form b = a × k, where k is a fixed constant across all pairs. Common multipliers in GL papers are ×2, ×3, ×4, ×5, and occasionally ×6 or ×7.

To identify: divide b by a for the first pair. Check the same quotient holds for the second pair. Then apply to find the missing number.

  2. Verify on pair 2: 2 × 5 = 10 ✔ — yes, it works!

⚠️ Watch Out!

Multiplication Blindness: Students often miss ×4 or ×5 and start hunting for additions instead. Always try dividing b by a before anything else. If the result is a clean whole number, multiplication is your rule.

✏️ Worked Example 2 (Harder)

Question: [6, 42] [4, 28] [9, ?]

  1. Try ×: 42 ÷ 6 = 7
  2. Verify: 4 × 7 = 28 ✔
  3. Apply: 9 × 7 = 63

Trap: Some students try ×6 first because 6 is the first number. Always DIVIDE to find the multiplier — don't guess from the number itself.

Addition & Subtraction Rules

✔
🧒 Simple Explanation

Sometimes the machine just adds or takes away the same number every time. So if you put in 5 and get 13, it added 8. If you put in 10 and get 18, it's still adding 8!

To spot this: subtract the first number from the second. If you always get the same answer, that's your rule.

📖 Full Explanation

An additive rule takes the form b = a + k or b = a − k, where k is a fixed constant. To identify: compute b − a for each given pair. If both differences are equal, that is k. Then apply b = a + k (or a − k) to find the missing value.

Near-miss trap: +6 versus ×2+2 can look very similar for small numbers — always verify on BOTH pairs.

✏️ Worked Example 1

Question: [4, 11] [9, 16] [6, ?]

  1. Find the difference: 11 − 4 = 7. Maybe rule is +7.
  2. Verify pair 2: 9 + 7 = 16 ✔
  3. Apply: 6 + 7 = 13
Answer: 13
⚠️ Watch Out!

Near-Miss Trap: For the pair [6, 20], you might think "+14". But if pair 2 is [7, 23], check: 7+14=21≠23. So the rule isn't +14. In this case the rule is ×3+2. Always confirm on both pairs before committing!

✏️ Worked Example 2 (Harder — Subtraction)

Question: [18, 9] [24, 15] [30, ?]

  1. Difference: 9 − 18 = −9. Maybe rule is −9.
  2. Verify: 24 − 9 = 15 ✔
  3. Apply: 30 − 9 = 21
Answer: 21

Combination Rules (× then +/−)

✔
🧒 Simple Explanation

Sometimes the machine does two things: first it multiplies, then it adds or takes away a little bit. So instead of just ×3, it might be ×3 then +2.

You'll spot this when the differences between pairs (b−a) are not the same. That's your warning that a simple + rule won't work — time to try multiplying first, then adjusting.

📖 Full Explanation

Combination rules take the form b = (a × m) + c, where m is the multiplier and c is a fixed constant (which may be negative). Steps to identify:

  1. Check if b−a is the same for both pairs. If not, it's a combo rule.
  2. Try small multipliers (×2, ×3). See if the difference (b − a×m) is the same for both pairs.
  3. That consistent difference is your constant c.
  4. Apply and verify: b = a×m + c.
✏️ Worked Example 1

Question: [3, 11] [5, 19] [4, ?]

  1. Differences: 11−3=8, 19−5=14. Not equal → combo rule.
  2. Try ×2: 3×2=6, 6+?=11 → add 5. Check: 5×2=10, 10+5=15 ✗
  3. Try ×3: 3×3=9, 9+?=11 → add 2. Check: 5×3=15, 15+2=17 ✗
  4. Try ×4: 3×4=12 — too big already. Skip.
  5. Back to ×3: nope. Try ×2: pair 1 gives +5, pair 2 gives 19−10=+9. Different → ×2 fails.
  6. Try ×3+2: nope. Try ×4−1: 3×4−1=11 ✔, 5×4−1=19 ✔! Rule is ×4−1.
  7. Apply: 4×4−1 = 16−1 = 15
Answer: 15
⚠️ Watch Out!

Overfitting: Don't invent a strange rule like ×3+5−2 when ×3+3 works. Always start with the simplest multiplier and keep the adjustment as small as possible. If your rule has more than two operations, you've likely made an error.

✏️ Worked Example 2 (Harder)

Question: [5, 27] [3, 17] [7, ?]

  1. Differences: 27−5=22, 17−3=14. Not equal → combo.
  2. Try ×5: 5×5=25, 25+?=27 → +2. Check: 3×5=15, 15+2=17 ✔! Rule: ×5+2.
  3. Verify: 5×5+2=27 ✔, 3×5+2=17 ✔
  4. Apply: 7×5+2 = 35+2 = 37
Answer: 37

Square & Power Rules

✔
🧒 Simple Explanation

Sometimes the machine squares your number — that means it multiplies it by itself! So 4 becomes 16 (because 4×4=16), and 5 becomes 25 (because 5×5=25).

You'll spot this when numbers jump a lot. If 3 becomes 8 or 9, think about squaring. Sometimes it's a² then ±1.

📖 Full Explanation

Square rules take the form b = a² or b = a² ± c. When numbers increase rapidly relative to the input, consider squaring. Steps:

  1. Square the first number in pair 1. Is it close to b?
  2. If b = a², verify on pair 2.
  3. If b = a² ± c, find c from pair 1, verify it on pair 2.
  4. Apply to find the missing number.

GL Scholarship trap: [3,8][5,24] — these look irregular, but 3²−1=8 and 5²−1=24. Always try a²−1, a²+1 when squaring is close.

✏️ Worked Example 1

Question: [3, 8] [5, 24] [4, ?]

  1. Numbers jump a lot → try squaring.
  2. 3² = 9. Close to 8. Try 3²−1 = 8 ✔
  3. Verify: 5²−1 = 25−1 = 24 ✔
  4. Apply: 4²−1 = 16−1 = 15
Answer: 15
⚠️ Watch Out!

Dual-Rule Trap: If pair 2 has [7, 49], you might think "squaring" because 7²=49. But if pair 1 is [6, 42], squaring fails (6²=36≠42). Always check pair 1 FIRST. The rule must survive BOTH pairs.

✏️ Worked Example 2 (Scholarship)

Question: [2, 3] [4, 15] [5, ?]

  1. Try squaring: 2²=4, 3≠4. Try 2²−1=3 ✔
  2. Verify: 4²−1=15 ✔
  3. Apply: 5²−1=25−1=24
Answer: 24

Reverse & Mixed Questions

✔
🧒 Simple Explanation

Some questions hide the missing number on the LEFT instead of the right. This means the machine has already done its job, and you need to work backwards to find the original number.

Think of it like knowing a machine adds 5, and the output was 20. So the input must be 15. Run the machine in reverse!

📖 Full Explanation

For reverse questions, first identify the rule using the two complete pairs, then apply the inverse operation:

  • If rule is ×k, inverse is ÷k
  • If rule is +k, inverse is −k
  • If rule is ×m + c, inverse is (b − c) ÷ m
  • If rule is a², inverse is √b
⚠️ Watch Out!

Don't apply the rule forwards! Students often spot the rule and accidentally apply it to the result instead of reversing it. If the rule is ×4 and the output is 28, the input is 28÷4=7, NOT 28×4=112.
