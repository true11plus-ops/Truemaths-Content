How Mixed Word Rules Work

🧒 Simple Explanation

You're given two pairs of example words. Each pair shows two "input" words and one "output" word. Your job is to spot the secret recipe: which letters were taken, from which word, and in what order?

Think of it like a mixing machine. Two words go in, some letters are picked out, and a new word comes out. Once you figure out the recipe, you can run any two words through the machine!

📖 Full Explanation

Each question gives you two example triplets: (Word1, Word2) → Result. The result is built by extracting specific letters from Word1 and/or Word2 according to a fixed positional rule. You must:

  1. Label each letter by position: Word1 letters = L1, L2, L3… Word2 letters = R1, R2, R3…
  2. Match each letter in the result to its source — which word and which position.
  3. Verify the same rule works on the second example pair.
  4. Apply the confirmed rule to the new pair to find the answer.
⚡ Speed Strategy — Always Follow This Order
  • 01Quick-scan first: Does the result start with letters from Word1? Does it end with letters from Word2? Check the obvious chunks first.
  • 02Count the letters: How long is the result? That tells you how many letters were taken total.
  • 03Label and map: Write L1 L2 L3 / R1 R2 R3 above each word. Match result letters to positions.
  • 04Test on pair 2: Apply the rule you found to the second example. If the result matches, your rule is correct.
  • 05Apply to the new pair: Only after confirming the rule on both examples.

🆘 Stuck? Fallback Protocol

If the start doesn't match: try looking at the end of the result first — sometimes the rule works backwards.

If one word seems to dominate: try treating all letters as coming from one source only.

If letters seem to alternate: check L1, R1, L2, R2 or similar interleaving patterns.

Abandon and retry: if your rule fails on pair 2, drop it completely — don't force it.

First + Last Chunks

✔
🧒 Simple Explanation

The most common rule: take the first few letters of Word 1, then add the last few letters of Word 2 (or vice versa). It's like chopping two words in half and gluing different pieces together.

Spotting it: the result's first letter matches Word 1's first letter, and the result ends with letters from Word 2.

📖 Full Explanation

Rules of this type take the form: W1[1..n] + W2[m..end]. The split point (n and m) is fixed across all pairs. To find n: count how many letters in the result come from Word 1. To find m: trace the remaining letters back to Word 2's positions.

✏️ Worked Example 1

Given pairs:

CAKE+BIRD→CIRD
MOON+STAR→?

Step-by-step:

  1. Label CAKE: C=L1, A=L2, K=L3, E=L4. Label BIRD: B=R1, I=R2, R=R3, D=R4.
  2. Result CIRD: C=L1 ✓, I=R2, R=R3, D=R4.
  3. Rule: L1 + R2 + R3 + R4 (first letter of Word1, last 3 letters of Word2).
  4. Verify on pair 1: C(L1) + I(R2) R(R3) D(R4) = CIRD ✓
  5. Apply to MOON + STAR: M=L1. STAR: S=R1, T=R2, A=R3, R=R4. Answer = M + T + A + R = MTAR.
Rule: W1[1] + W2[2] + W2[3] + W2[4] → i.e. first letter of Word1, then letters 2–4 of Word2
⚠️ Watch Out!

"It must be a real word": The result does NOT have to be a dictionary word. MTAR and CIRD are valid answers. Never change your answer just because it "doesn't look like a word." Follow the rule, trust the method.

Index drift: Students sometimes slip off by one — picking letter 3 when the rule says letter 2. Always number every letter before extracting.

✏️ Worked Example 2 (Harder — Finding the Split)

Given pairs:

PLANT+SHORE→PORE
BRICK+STONE→BONE
TRACK+SMILE→?
  1. PLANT: P=L1,L=L2,A=L3,N=L4,T=L5. SHORE: S=R1,H=R2,O=R3,R=R4,E=R5.
  2. Result PORE: P=L1, O=R3, R=R4, E=R5.
  3. Tentative rule: L1 + R3 + R4 + R5 (first letter of Word1 + letters 3,4,5 of Word2).
  4. Verify on pair 2: BRICK→B=L1. STONE: O=R3,N=R4,E=R5. B+ONE = BONE ✓
  5. Apply to TRACK+SMILE: T=L1. SMILE: S=R1,M=R2,I=R3,L=R4,E=R5. T+I+L+E = TILE.
Rule: W1[1] + W2[3] + W2[4] + W2[5]

Alternating Letter Rules

✔
🧒 Simple Explanation

Instead of taking a chunk from one word and a chunk from another, some rules alternate — take one from the left, one from the right, one from the left, one from the right. Like a zip — the two sides interleave!

Spotting it: if you can't find the result as a clean chunk from either word, check if the letters alternate between the two sources.

📖 Full Explanation

Alternating rules follow a pattern like: L1, R1, L2, R2 (take letter 1 from Word1, letter 1 from Word2, letter 2 from Word1, letter 2 from Word2) — or similar interleaving patterns. The key is that letters switch source at every step.

✏️ Worked Example 1 — L1, R1, L2, R2
COLD+FARM → CFOA
SHIP+BIRD → SBHI
  1. COLD: C=L1,O=L2,L=L3,D=L4. FARM: F=R1,A=R2,R=R3,M=R4.
  2. Result CFOA: C=L1, F=R1, O=L2, A=R2.
  3. Rule: L1, R1, L2, R2 — alternating, one from each word in turn.
  4. Verify pair 2: SHIP→S=L1,H=L2. BIRD→B=R1,I=R2. L1,R1,L2,R2 = S,B,H,I = SBHI ✓
Rule: W1[1], W2[1], W1[2], W2[2] — alternating by position
⚠️ Watch Out!

Pattern lock-in: Don't assume every question follows the "first chunk + last chunk" rule. When you see a result that doesn't look like a clean split, try alternating. Write L1 R1 L2 R2 above the result letters to test it.

✏️ Worked Example 2 — R1, L1, R2, L2 (reversed order)
PLAN+GRIT → GPLA
STAR+BOLD → BOST
  1. PLAN: P=L1,L=L2,A=L3,N=L4. GRIT: G=R1,R=R2,I=R3,T=R4.
  2. Result GPLA: G=R1, P=L1, L=L2, A=L3.
  3. Hmm — G=R1, P=L1, L=L2, A=L3. That's R1,L1,L2,L3 — not clean alternating.
  4. Recheck: GPLA. G=R1, P=L1, L=L2, A=L3. Try R1,L1,L2,L3. Verify pair 2: STAR→S=L1,T=L2,A=L3. BOLD→B=R1. R1,L1,L2,L3 = B,S,T,A = BSTA. But pair 2 gives BOST. Doesn't match.
  5. Retry: BOST. B=R1, O=R2, S=L1, T=L2. Rule: R1,R2,L1,L2. Check pair 1: G=R1,R=R2,P=L1,L=L2 = GRPL. But pair 1 gives GPLA. Doesn't match either.
  6. Try: GPLA. G=GRIT[1], P=PLAN[1], L=PLAN[2], A=PLAN[3]. Rule: R1,L1,L2,L3. Pair 2: B=BOLD[1], S=STAR[1], T=STAR[2], A=STAR[3]? But STAR[3]=A, pair 2 gives BOST position 3=S=STAR[1] again — contradiction.
  7. Better approach: BOST: B=BOLD[1], O=BOLD[2], S=STAR[1], T=STAR[2]. Rule: R1,R2,L1,L2. Check pair 1: GRIT[1,2]=G,R. PLAN[1,2]=P,L. → GRPL. But pair1=GPLA. Mismatch — this example is inconsistent.

⚠ This example had an inconsistency. Below is the clean version:

PLAN+GRIT → GRPL
STAR+BOLD → BOST
  1. GRPL: G=GRIT[1]=R1, R=GRIT[2]=R2, P=PLAN[1]=L1, L=PLAN[2]=L2.
  2. Rule: R1, R2, L1, L2.
  3. Verify pair 2: BOLD[1,2]=B,O. STAR[1,2]=S,T. → B,O,S,T = BOST ✓
Rule: W2[1], W2[2], W1[1], W1[2]

Single-Source Rules

✔
🧒 Simple Explanation

Sometimes the machine only uses letters from one word — all of them! You pick specific letters from the same word and put them together. The second word just sits there, not used at all.

Spotting it: if you can trace ALL the result letters back to one word, stop looking at the other word.

📖 Full Explanation

Single-source rules extract letters only from Word 1 (or only from Word 2), at specified positions. The result is built entirely from one source. Common forms: W1[1,3,5], W2[2,4,6], W1[last 3], W2[middle 3], etc.

✏️ Worked Example 1 — Positions 1,3,5 from Word 1
BRAVE+CLOUD → BVE
STING+PLANT → SIG
  1. BRAVE: B=L1,R=L2,A=L3,V=L4,E=L5. CLOUD: C=R1,L=R2,O=R3,U=R4,D=R5.
  2. Result BVE: B=L1, V=L4... wait, that's not a skip pattern of 1,3,5.
  3. Recheck: BVE. B=BRAVE[1], V=BRAVE[4], E=BRAVE[5]. That's positions 1,4,5.
  4. Verify with STING: S=pos1, I=pos3... wait STING[4]=N, STING[5]=G. SIG: S=pos1, I=pos3, G=pos5. That's 1,3,5.
  5. Back to BVE: BRAVE[1]=B, BRAVE[3]=A, BRAVE[5]=E → BAE, not BVE.
  6. Resolution: The pair is inconsistent. Clean version below:
BRAVE+CLOUD → BAE
STING+PLANT → SIG
  1. BRAVE: B=1,R=2,A=3,V=4,E=5. Result BAE = B(1), A(3), E(5). Pattern: positions 1,3,5 of Word1.
  2. Verify STING: S(1), I(3), G(5) = SIG ✓
  3. Note: CLOUD is completely unused! All letters come from Word1.
Rule: W1[1] + W1[3] + W1[5] — skip positions, single source
⚠️ Watch Out!

Partial matching trap: Students find 2 matching letters and assume the third comes from Word2. Always trace ALL result letters before deciding which source to use. If all trace to one word, the other word is irrelevant.

Dominant word pattern: In some questions, 3 letters come from Word1 and 1 letter from Word2. Don't assume it's all-or-nothing — count carefully.

✏️ Worked Example 2 — Middle Letters from Word 2
FROST+GROAN → ROA
BLAZE+PLANT → LAN
  1. GROAN: G=1,R=2,O=3,A=4,N=5. Result ROA = R(2),O(3),A(4). Positions 2,3,4 of Word2.
  2. Verify PLANT: P=1,L=2,A=3,N=4,T=5. LAN = L(2),A(3),N(4) ✓
  3. FROST and BLAZE are completely unused. Rule: middle 3 letters of Word2.
Rule: W2[2] + W2[3] + W2[4] — middle three letters of Word2 only

Reverse & Skip Rules

✔
🧒 Simple Explanation

The trickiest questions take letters in reverse order from a word — so instead of taking letters 1,2,3, they take letters 3,2,1 (backwards). Or they skip positions, jumping over some letters to take specific ones.

Spotting reversal: if the result letters seem to be from one word but in the wrong order, try reading that word backwards!

📖 Full Explanation

Reverse rules take letters from a word in reverse positional order: W2[last], W2[second-last], etc. Skip rules jump non-consecutively: W1[1,3] or W2[2,4,6]. These can also combine with standard chunk rules.

✏️ Worked Example 1 — Reverse Last 3 of Word 2
FOLD+CRISP → FPSI
GLOW+BLUNT → GTNU
  1. CRISP: C=R1,R=R2,I=R3,S=R4,P=R5. FOLD: F=L1,O=L2,L=L3,D=L4.
  2. Result FPSI: F=L1. Then P,S,I. P=CRISP[5]=R5, S=CRISP[4]=R4, I=CRISP[3]=R3.
  3. Pattern: F(L1) + P(R5) + S(R4) + I(R3) — taking Word2 letters in reverse from position 5 back to 3.
  4. Rule: W1[1] + W2[5,4,3] (reverse of last 3 of Word2).
  5. Verify pair 2: GLOW[1]=G. BLUNT: B=R1,L=R2,U=R3,N=R4,T=R5. W2[5,4,3]=T,N,U → GTNU ✓
Rule: W1[1] + W2[5] + W2[4] + W2[3] — first of Word1, then last 3 of Word2 in reverse
⚠️ Watch Out!

Reversal blindness: If you can find all the letters but they seem scrambled, always try reading the source word backwards. Don't assume letters must appear in the same order they appear in the original word.

✏️ Worked Example 2 — Skipping Rule
BRIGHT+CLAMPS → BCLA
PLANET+STRONG → PSTR
  1. BRIGHT: B=L1. CLAMPS: C=R1,L=R2,A=R3,M=R4,P=R5,S=R6. BCLA: B=L1, C=R1, L=R2, A=R3.
  2. Rule: W1[1] + W2[1,2,3] — first letter of Word1 then first 3 of Word2.
  3. Verify: PLANET[1]=P. STRONG[1,2,3]=S,T,R. P+STR = PSTR ✓
Rule: W1[1] + W2[1,2,3] — simple but uses 6-letter words as a decoy
