Number Series

Find the hidden pattern. Predict the next number. Beat the exam.

📚 8 Sub-Skills ⏱️ ~30 sec per question 🎯 GL Assessment Format 🏅 4 Difficulty Tiers

What is Number Series?

You are given a row of numbers that follow a secret pattern. Your job is to work out the rule and find the next number. The GL Assessment gives you 5 choices — but knowing the right strategy will get you there in under 15 seconds.

5 Answer Options (A–E) Multiple-choice format ~30 seconds per question Check your rule every time!
🌳

The 5-Step Decision Tree (Use This Every Time)

  1. Step 1 — Simple difference: Is the gap between numbers always the same? (e.g. +3, +3, +3)
  2. Step 2 — Changing difference: Does the gap grow or shrink? (e.g. +2, +4, +6, +8)
  3. Step 3 — Alternating: Do numbers jump up-and-down? Try splitting into two rows.
  4. Step 4 — Multiplication or division: Is each number ×2 or ÷3 of the last?
  5. Step 5 — Squares / Fibonacci: Do you recognise 1,4,9,16 or 1,1,2,3,5?
⏰ Time Pressure Rule
  • If you haven't spotted the pattern in 10–15 seconds → skip and come back. Never waste a full minute on one question.

Sub-Skill 1: Constant Arithmetic Sequences

0/16 answered
✓ Done
😊

Simple Explanation (Age 9)

Imagine you are climbing stairs. Every step goes up by exactly the same amount. In a constant sequence, the gap between every number is always the same — like climbing 3 steps at a time, every single time.

Think of it like: 🚶‍♂️ Walk 4 paces, walk 4 more, walk 4 more… the pattern never changes!

📖

Full Explanation

A constant arithmetic sequence increases or decreases by the same fixed value (the "common difference") at every step. To find the next term: calculate the difference between consecutive terms, confirm it is the same throughout, then add or subtract it from the last term.

  2. 2

  3. 3
    Next: 13 + 3 = 16
✅ Answer: 16
⚠️ Watch Out!
  • With large starting numbers (e.g. 142, 149…) students make arithmetic slips. Always write down the gap — don't do it in your head.
  • In descending sequences (e.g. 30, 24, 18…) students sometimes add instead of subtract. Check direction!

Sub-Skill 2: Progressive Arithmetic

0/16 answered
✓ Done
😊

Simple Explanation

Instead of climbing the same number of steps each time, imagine the steps get bigger and bigger. First you climb 2 steps, then 3, then 4, then 5… The gap keeps growing by the same amount each time!

🪜 It's like a staircase where each step is one step taller than the last.

📖

Full Explanation

In a progressive arithmetic sequence, the differences between consecutive terms are not constant — they themselves form an arithmetic sequence (e.g., +2, +4, +6, +8 — the differences increase by 2 each time). You must calculate the differences of the differences ("second differences") to find the pattern.

Sub-Skill 3: Alternating (Interlocking) Sequences

0/16 answered
✓ Done
😊

Simple Explanation

Imagine two friends taking turns to speak. Friend A says something, then Friend B, then A, then B… If you cover up Friend B's turns, Friend A has their own separate pattern. Alternating sequences are really TWO hidden sequences pretending to be one.

🎭 Visual trick: If numbers jump up-and-down oddly → try splitting into every OTHER number.

📖

Full Explanation

An alternating (interlocking) sequence consists of two independent arithmetic sequences woven together. The odd-position terms (1st, 3rd, 5th…) follow one rule; the even-position terms (2nd, 4th, 6th…) follow a different rule. To identify: if the differences alternate between positive and negative (or vary irregularly), separate the sequence into two strands.

Worked Example — Easy
Find the next: 3, 15, 6, 12, 9, 9, (?)
  1. 1
    Numbers jump: 3→15 (+12), 15→6 (−9)… — up then down. Try splitting!
  2. 2
    Strand A (positions 1,3,5): 3, 6, 9 → rule is +3
  3. 3
    Strand B (positions 2,4,6): 15, 12, 9 → rule is −3
  4. 4
    Next is position 7 (odd) → Strand A → 9 + 3 = 12

⚠️ Watch Out!
  • Students apply the rule they just used to the NEXT term too. Remember: Strand A's rule only applies to Strand A!
  • Long sequences (7+ numbers) hide the skip. Always write down which position the answer is in (odd or even).
  • Visual trigger: if numbers jump up-and-down → always try splitting first.
Worked Example — Harder (Compound alternating: ×2, +3)
Find the next: 2, 6, 7, 21, 22, 66, (?)
  1. 1
    Differences look chaotic. Split it!
  2. 2
    Strand A (pos 1,3,5): 2, 7, 22 → ×3+1 (2×3+1=7, 7×3+1=22)
  3. 3

  4. 4
    Next is position 7 (odd) → Strand A → 22 × 3 + 1 = 67
✅ Answer: 67

Sub-Skill 4: Multiplicative & Geometric Sequences

0/16 answered
✓ Done
😊

Simple Explanation

Instead of adding the same number each time, you multiply. Like a magic doubling machine: put 3 in, get 6 out. Put 6 in, get 12 out. The numbers grow fast!

💸 Think of it like money doubling in a bank every year: 1, 2, 4, 8, 16, 32…

📖

Full Explanation

A geometric (multiplicative) sequence uses a constant ratio — each term is multiplied (or divided) by the same value. Also includes square sequences (1, 4, 9, 16, 25…), cube sequences (1, 8, 27, 64…), and prime number sequences (2, 3, 5, 7, 11…).

Worked Example — Squares
Find the next: 1, 4, 9, 16, (?)
  1. 1
    Differences: +3, +5, +7 — odd numbers! Or simply: these are 1², 2², 3², 4²
  2. 2
    Next: 5² = 25
✅ Answer: 25
⚠️ Watch Out!
  • Square Blindness: Seeing 4, 9, 16 and calculating differences (+5, +7) instead of recognising them as 2², 3², 4². Learn your squares to 15²!
  • The sequence may start mid-way: e.g., 25, 36, 49… is still squares (5², 6², 7²)
Worked Example — Harder (Offset squares)
Find the next: 5, 10, 17, 26, (?)
  1. 1
    Differences: +5, +7, +9 — odd differences
  2. 2
    Check squares: 4+1=5, 9+1=10, 16+1=17, 25+1=26 → rule is n²+1
  3. 3
    Next: 6² + 1 = 37
✅ Answer: 37

Sub-Skill 5: Position-Based Sequences (n², n(n+1))

0/8 answered
✓ Done
😊

Simple Explanation

Sometimes the secret is about the position of the number. The 1st number depends on 1, the 2nd on 2, the 3rd on 3… You need to spot what is special about each position number.

🪑 Imagine numbered seats in a cinema. Your seat number tells you how many popcorn boxes you get. Seat 1 → 2 boxes. Seat 2 → 6 boxes. Seat 3 → 12 boxes. The seat NUMBER decides the answer!

📖

Full Explanation

In position-based sequences, the nth term is defined by a formula involving n. Common patterns: n² (squares), n(n+1) (triangular pairs), 2n, n²+k, n²−k. To identify: check if differences form consecutive odd numbers (squares) or consecutive even numbers (n(n+1)).

Worked Example
Find the next: 2, 6, 12, 20, 30, (?)
  1. 1
    Differences: +4, +6, +8, +10 — even numbers, going up by 2
  2. 2
    Try n(n+1): 1×2=2, 2×3=6, 3×4=12, 4×5=20, 5×6=30 ✓
  3. 3
    Next: n=6 → 6×7 = 42
✅ Answer: 42
⚠️ Watch Out!
  • Students try to use differences only and miss the position pattern. Always ask: "Could this be n² or n(n+1)?"

Sub-Skill 6: Compound (Two-Step) Rules

0/8 answered
✓ Done
😊

Simple Explanation

A two-step rule is like a machine with two buttons. First you press Button 1 (e.g. "×2"), then Button 2 (e.g. "+1"). Both buttons must be pressed in order to get the next number.

🏭 A factory machine: put in 5, it ×2 = 10, then +1 = 11. Put in 11, it ×2 = 22, then +1 = 23!

📖

Full Explanation

Compound (two-step) rules apply two operations to each term to generate the next — e.g., ×2 then +1, or +5 then ÷2. The differences between consecutive terms will form a geometric sequence (if ×k is involved). To spot: calculate differences — if they double or triple each time, try a two-step rule.

Worked Example — ×2+1

  2. 2
    Test ×2+1: 2×2+1=5 ✓, 5×2+1=11 ✓, 11×2+1=23 ✓
  3. 3
    Next: 47×2+1 = 95
✅ Answer: 95
⚠️ Watch Out!
  • Students often only do HALF the rule — they multiply but forget to add!
  • Order matters: ×2+1 gives different results from +1×2. Always test both.

Sub-Skill 7: Fibonacci-Style Sequences

0/8 answered
✓ Done
😊

Simple Explanation

To get the next number, you add the two numbers before it. Simple! Start with 1 and 1: add them to get 2. Then 1+2=3. Then 2+3=5. It keeps going!

🐇 This is the famous rabbit pattern from nature. Each number is the sum of the two before it.

📖

Full Explanation

A Fibonacci-style sequence is defined by the recurrence T(n) = T(n−1) + T(n−2). The sequence may start with any two values, not necessarily 1, 1. Check: does each term equal the sum of the previous two?

Worked Example
Find the next: 1, 1, 2, 3, 5, 8, (?)
  1. 1
    Check: 1+1=2 ✓, 1+2=3 ✓, 2+3=5 ✓, 3+5=8 ✓
  2. 2
    Next: 5+8=13
✅ Answer: 13
⚠️ Watch Out!
  • Students add only 1 previous term, not 2. Always: add the TWO terms before the blank.

Sub-Skill 8: Mixed Operations & GL Traps

0/8 answered
✓ Done
😊

Simple Explanation

GL examiners sometimes try to trick you. The first few numbers might look like one pattern, then suddenly change. Or the rule mixes adding AND multiplying AND dividing. Never assume after just 2 numbers — always check all of them!

🕵️ Be a detective: check your rule against EVERY number before trusting it.

⚠️ Classic GL Traps
  • False pattern trap: 2, 4, 8, 14, 22 — looks like ×2 but is actually +2, +4, +6, +8
  • Overfitting: Finding a rule that works for the first 2 gaps but fails at the 3rd
  • "Nice numbers" trap: Picking a round answer that looks right but isn't
  • Stopping too early: Only checking 2 steps, not verifying the whole chain
Worked Example — The Wrong-First-Instinct Example
Find the next: 2, 4, 8, 14, 22, (?)
  1. 1
    First instinct: 2, 4, 8 → looks like ×2! So next would be 16? Let's check…
  2. 2
    8 × 2 = 16 ≠ 14 ❌ — the rule breaks! First instinct is WRONG.
  3. 3
    Differences: +2, +4, +6, +8 → progressive! Next difference: +10
  4. 4
    Answer: 22 + 10 = 32
✅ Answer: 32
