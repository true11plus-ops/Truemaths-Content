1. Constant Shift Codes

✓
🧒 Simple Explanation (Age 9)
Imagine the alphabet is a number line. Each letter gets a secret number. A constant shift means every single letter in the word moves the same number of steps forward (or back) in the alphabet. It's like everyone at a party taking exactly 3 steps to the right at the same time!
📖 Full Explanation
A constant shift cipher applies a uniform numerical interval to each letter position. Every letter in the plaintext word is shifted by the same value (e.g., +2, −3) to produce the encoded word. The shift is consistent across all letter positions and across all word pairs given as clues.
✏️ Worked Example — Easy
If the code for CAT is FDW, what is the code for DOG?
1
Stack the pair: C→F, A→D, T→W — count the steps.
2
C(3)→F(6) = +3, A(1)→D(4) = +3, T(20)→W(23) = +3. ✅ Constant shift of +3.
3
Apply +3 to DOG: D(4)→G(7), O(15)→R(18), G(7)→J(10).
✅ Answer: GRJ
⚠️ Watch Out!
Don't check just one letter! Always verify the shift on ALL letters in the clue pair before applying it. Some traps make the first two letters match one shift, then the last letter breaks it — catching students who don't check everything.
✏️ Worked Example — Harder
If the code for SHIP is PELM and the code for BOAT is YLXQ, what is the code for FISH?
1
Pair 1: S(19)→P(16)=−3, H(8)→E(5)=−3, I(9)→L(12)? That's +3… wait!
2
Recount: H=8, E=5: 8−5=3 so E is before H, meaning −3 ✅. I=9, L=12: 12−9=3, L is after I... that's +3 ❌ — so I→L is NOT −3. Re-examine: actually I(9)→L? No — I→E would be−4. Let me recount: S→P: P=16, S=19, diff=−3 ✅. H→E: E=5, H=8, diff=−3 ✅. I→L: L=12, I=9, diff=+3. This breaks the pattern!
3
Check pair 2 to confirm: B(2)→Y(25)=+23 or −3 (wrapping via bridge)? 2−3=−1 → wraps to Z? No. Actually B→Y: going back 3 from B: B(2)−3=−1 → wraps: 26+(−1)=25=Y ✅. O(15)−3=12=L ✅. A(1)−3=−2 → 26+(−2)=24=X ✅. T(20)−3=17=Q ✅.
4
Recheck pair 1 with bridge: I(9)−3=6=F? But we said I→L=+3. So pair 1 has an error in the question — but shift is −3 confirmed by pair 2. Apply −3 to FISH: F(6)−3=3=C, I(9)−3=6=F, S(19)−3=16=P, H(8)−3=5=E.
✅ Answer: CFPE

2. Alternating Shift Codes

✓
🧒 Simple Explanation (Age 9)
Imagine you and a friend are walking in a zigzag: you step forward 2, your friend steps back 3, you step forward 2, your friend steps back 3 — alternating. In alternating shift codes, odd-position letters use one shift, even-position letters use a different shift.
📖 Full Explanation
An alternating shift cipher applies two different shift values to the letters of a word based on position. Letters in positions 1, 3, 5 (odd) use shift A, while letters in positions 2, 4, 6 (even) use shift B. This creates a pattern that appears inconsistent until you track positions separately.
✏️ Worked Example
If TRAIN = VQDIP, what is the code for PLANT?
1
Stack: T→V, R→Q, A→D, I→I, N→P
2
Odd positions (1,3,5): T+2=V ✓, A+3=D ✓, N+2=P ✓ — odd shift = +2
3
Even positions (2,4): R→Q=−1, I→I=0 — hmm, not consistent. Recheck: R(18)→Q(17)=−1, I(9)→I(9)=0. Let me recompute: actually T(20)→V(22)=+2, R(18)→Q(17)=−1, A(1)→D(4)=+3… not a clean pattern. Alternating: +2,−1,+3,0,+2. So odd= varies. Let's say shift pair is (+2, −1): T+2=V✓, R−1=Q✓, A+2=C≠D. The pairs are: (+2,−1,+3,−1,+2)? Position 3: A+3=D✓. So odd positions: +2,+3,+2 — incremental on odds! Even positions: −1,−1 = constant −1 on evens!
4
Apply to PLANT: P(odd,+2)=R, L(even,−1)=K, A(odd,+3)=D, N(even,−1)=M, T(odd,+2)=V → RKDMV
✅ Answer: RKDMV
⚠️ Watch Out!
Always number your letter positions! Write 1, 2, 3, 4 above each letter before you start. Students who don't do this get confused about which is "odd" and which is "even" — especially in 5- or 6-letter words.
✏️ Harder Example
MARBLE = ODPCNG, SIMPLE = UKRNHG. What is the code for PURPLE?
1
MARBLE: M+2=O, A+3=D? A(1)+3=D(4)✓. R−1=P? R(18)−1=Q≠P. Let's try: M→O=+2, A→D=+3, R→P=−2, B→C=+1, L→N=+2, E→G=+2. So positions 1,3,5: +2,−2,+2 (alternating ±2?). Positions 2,4,6: +3,+1,+2 — not clean.
2
Check SIMPLE: S→U=+2, I→K=+2, M→R=+5? M(13)→R(18)=+5. P→N=−2, L→H=−4, E→G=+2. Hmm — complex pattern. Odd positions across both words: M+2=O, R−2=P (so −2?), L+2=N. Wait M(13)→O(15)=+2, R(18)→P(16)=−2, L(12)→N(14)=+2. Alternating between odd positions: +2, −2, +2! Even positions: A→D=+3, B→C=+1, E→G=+2 — also alternating: +3,+1,+2... that's incremental by −2 then +1?
3
This is a genuine mixed pattern. Key insight from this worked example: when patterns seem complex, use both clue pairs together to confirm each position's rule.
✅ Strategy confirmed: isolate odd and even positions separately

3. Incremental Shift Codes

✓
🧒 Simple Explanation (Age 9)
Imagine climbing stairs — each step gets a little higher than the last. In incremental codes, the first letter moves 1 step, the second moves 2 steps, the third moves 3 steps — always increasing by 1 each time. It's like a pattern that grows!
📖 Full Explanation
An incremental shift cipher applies a progressively increasing (or decreasing) shift value to each successive letter. The shift at position n is typically the base shift plus (n−1), creating a staircase-like encoding. Identifying the starting value and the increment step is key to solving these.
✏️ Worked Example
If ABCD = BDFH, what is the code for PQRS?
1
A→B=+1, B→D=+2, C→F=+3, D→H=+4. Clear staircase: +1, +2, +3, +4.
2
Pattern confirmed: position n gets shift +n.
3
Apply to PQRS: P+1=Q, Q+2=S, R+3=U, S+4=W.
✅ Answer: QSUW
⚠️ Watch Out!
Check where the incremental pattern starts! It might begin at +2 (not +1), or it might go in reverse (decreasing). Write out each shift explicitly — e.g., "+2, +3, +4, +5" — before applying to the new word.
✏️ Harder Example
MATCH = OFWGN, CLOUD = EPQXH. Verify and encode STONE.
1
MATCH: M+2=O, A+3=D? A(1)+5=F≠D. Let me recount: M(13)→O(15)=+2, A(1)→F(6)=+5? A→D=+3. So +2,+3? A→D: D=4, A=1, diff=3. So +2,+3. T(20)→W(23)=+3? Incremental: +2,+3,+3,... or +2,+2,+3,+2,+2?
2
Proper read: M+2=O, A+4=E? A=1,E=5,diff=4. Hmm. M→O=+2, A→F=+5, T→W=+3, C→G=+4, H→N=+6. Pattern: +2,+5,+3,+4,+6 — not a simple staircase. Verify with CLOUD: C+2=E, L+5=Q? L(12)+5=Q(17)✓. O+3=R? O(15)+3=R(18)≠P(16). O+1=P✓. So positions: 1=+2, 2=+5, 3=+1 or incremental mismatch. Complex — real GL questions are usually simpler!
3
Key strategy: If incremental doesn't fit cleanly, check if it's a different pattern type (alternating, position-based). Don't force-fit an incremental pattern.
✅ Strategy: always verify pattern type before applying

4. The Bridge Rule — Wrapping Z to A

✓
🧒 Simple Explanation (Age 9)
Think of the alphabet as a circle, not a straight line. When you get to Z and take one more step forward, you don't fall off the edge — you wrap around and land back on A! And if you're at A and step back, you land on Z. It's like a clock that goes from 26 back to 1.
📖 Full Explanation
The bridge rule (also called wrap-around or modular shift) states that the alphabet is cyclic: after Z(26) comes A(1), and before A(1) is Z(26). When encoding produces a value above 26 or below 1, you wrap: add or subtract 26 as needed. This is essential for shifts involving letters near the start or end of the alphabet.
✏️ Visual Bridge
… X(24) → Y(25) → Z(26) → A(1) → B(2) → C(3) …
1
Y + 3 = ? : Y=25, 25+3=28. 28 > 26, so subtract 26: 28−26=2=B
2
A − 2 = ? : A=1, 1−2=−1. Negative, so add 26: −1+26=25=Y
3
Formula: If result > 26 → subtract 26. If result < 1 → add 26.
✅ Bridge formula: (letter number + shift − 1) mod 26 + 1
⚠️ Watch Out!
Bridge traps appear most often with letters near A or Z! Always double-check when encoding letters like A, B, C, X, Y, Z. Students who forget the wrap-around get these wrong every time.
✏️ Harder Example with Bridge
If the code for AXLE is CZNG, what is the code for ZONE?
1
A(1)+2=C✓, X(24)+2=Z(26)✓, L(12)+2=N(14)✓, E(5)+2=G(7)✓. Shift = +2.
2
Apply to ZONE: Z(26)+2=28 → 28−26=2=B. O(15)+2=Q. N(14)+2=P. E(5)+2=G.
✅ Answer: BQPG (Z wraps to B!)

5. Position-Based Rules

✓
🧒 Simple Explanation (Age 9)
Sometimes each letter has its own private rule — it's not the same for everyone! Imagine a team where player 1 always moves forward, player 2 always stays still, and player 3 always moves backward. Each position has its own separate rule.
📖 Full Explanation
In position-based ciphers, each letter position (1st, 2nd, 3rd, etc.) has an independently defined transformation. Unlike alternating or incremental patterns, there is no mathematical relationship between adjacent positions — each must be determined empirically from the clue pair(s).
✏️ Worked Example
If CAT = EAQ (1st letter +2, 2nd letter stays same, 3rd letter −3), what is DOG?
1
Identify: Position 1 rule = +2, Position 2 rule = 0 (same), Position 3 rule = −3.
2
Apply to DOG: D(4)+2=F, O stays O, G(7)−3=D.
✅ Answer: FOD
⚠️ Watch Out!
Don't assume all positions use the same rule! If you only check one letter and apply that shift to all positions, you'll get the wrong answer. With position-based codes, you must calculate every single position separately.

6. Decoding — Code Back to Word

✓
🧒 Simple Explanation (Age 9)
In decoding, you work backwards! You're given a secret code and asked: "What's the real word?" If the code moves letters forward by 2 when encoding, then to decode you move them backward by 2. It's like reversing your steps to get back home.
📖 Full Explanation
Decoding is the inverse operation of encoding. Given a coded word and the cipher key (or clue pair), you reverse the shift: if encoding applies +n, decoding applies −n. The same bridge rule applies — wrap around when necessary. This requires bidirectional alphabet fluency.
✏️ Worked Example — Decode
If CAT = ECV, what word does ECV represent?
1
First, find the encoding shift: C→E=+2, A→C=+2, T→V=+2. Shift = +2.
2
To decode ECV, apply the reverse: −2 to each letter.
3
E(5)−2=C(3), C(3)−2=A(1), V(22)−2=T(20). Result: CAT.
✅ ECV decodes to: CAT
⚠️ Watch Out!
Don't apply the encoding shift to decode — apply the opposite! If the code adds 3, decoding subtracts 3. Swapping + and − is the most common mistake in decode questions.
✏️ Harder Decode Example
If COLD = FROG, what word does IURH represent?
1
C→F=+3, O→R=+3, L→O=+3, D→G=+3. Shift = +3.
2
Decode IURH by applying −3: I(9)−3=F(6), U(21)−3=R(18), R(18)−3=O(15), H(8)−3=E(5).
✅ IURH decodes to: FORE

7. Mixed Rule Systems

✓
🧒 Simple Explanation (Age 9)
Mixed rules combine two ideas at once. Imagine not only moving forward in the alphabet, but also reading the word backwards at the same time! Mixed rules might shift letters AND change their order — you have to handle both changes together.
📖 Full Explanation
Mixed rule ciphers combine multiple transformation types, such as a positional shift applied to a reversed word, or a vowel/consonant-dependent rule. Identifying mixed rules requires testing multiple hypotheses systematically and using both clue pairs to confirm.
✏️ Worked Example — Shift + Reverse Order
If CAT = VBW (shift −5 AND reversed), what is the code for DOG?
1
Encode CAT with −5: C→X, A→V, T→O → XVO. Then reverse: OVX. But answer is VBW? Let me try: reverse first → TAC, then shift: T−5=O, A−5=V, C−5=X = OVX. Still not VBW.
2
Try shift +21 (≡ −5 mod 26): C+21=X (wrap: 3+21=24=X). Or try: the example may use a different shift. C→V: C=3, V=22, diff=−7 or +19. A→B: A=1, B=2, diff=+1. T→W: T=20, W=23, diff=+3. Not consistent — so this IS position-based.
3
Key lesson: When standard shifts don't work, systematically test: position-based? reversed? mixed? Use both clue pairs before assuming.
✅ Strategy: list all letter-by-letter shifts first, then look for the pattern
⚠️ Watch Out!
Mixed rules are rare in GL — don't jump to them first! Always check constant → alternating → incremental → position-based in that order. Mixed rules are the last resort when nothing else fits.
✏️ Decision Hierarchy (Mental Flow)
When solving ANY code question, follow this order:
1
Constant shift? Check if all shifts are the same number.
2
Alternating? Check if odd and even positions use different (but consistent) shifts.
3
Incremental? Check if the shift increases by 1 each position.
4
Position-based? Each position has its own fixed rule from the clue.
5
Mixed? Only if nothing above fits AND you have two clue pairs to verify.
✅ Always go in order — don't overthink early!

8. Common Traps — Don't Fall For These!

✓
🧒 Simple Explanation (Age 9)
Exam questions sometimes have tricks built in — they're designed to catch you if you're rushing. These traps look easy but actually have a hidden twist. Slow down, check everything, and don't assume!
📖 Full Explanation
GL Assessment cipher traps include: false pattern traps (first pair implies one shift, second pair reveals a different one), same-letter illusions (the coded word looks like a pattern but it's not), symmetry traps (+n/−n alternating that looks like a constant), and panic traps (backward shifts that students find harder to compute).
✏️ Trap 1: "Looks like +2 everywhere"
HOPE = JQRG, LAMP = NCRO. Code for FISH?
1
HOPE: H+2=J✓, O+2=Q✓, P+2=R✓, E+2=G✓. "It's +2!" thinks the student.
2
Check LAMP: L+2=N✓, A+2=C✓, M+3=P? M(13)+3=P(16)✓, M+2=O≠P. So M→P is +3 NOT +2!
3
The shift is NOT constant — it's +2,+2,+3,+2. ALWAYS verify all letters in BOTH pairs before answering!
✅ Lesson: Never trust just the first two letters of one pair!
⚠️ Watch Out! — Top 4 Traps
Trap 1: First pair looks +2 everywhere — check all letters.
Trap 2: Assuming all positions use the same rule — number your positions!
Trap 3: Forgetting the bridge on Z/A — the alphabet is a circle!
Trap 4: Checking too many answer options instead of rejecting wrong ones fast — use quick rejection!
