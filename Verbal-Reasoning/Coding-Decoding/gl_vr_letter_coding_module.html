Consistent (Fixed) Shift

✓
🧒 Simple Explanation

Imagine every letter in a word takes the same number of steps forward in the alphabet. Like if you move every letter 2 steps forward, then A becomes C, B becomes D, C becomes E — all jumping the same amount. If you know the jump size, you can decode any word!

📘 Full Explanation

A consistent shift (also called a fixed or uniform shift) is when every letter in the source word is shifted by exactly the same numeric value to produce the code. The shift can be positive (forward in the alphabet) or negative (backward). All positions in the word obey the same rule. This is the most frequently tested pattern in GL Assessment papers.

CAT (ECV) : DOG ( ? )
  • Find shift for C → E: count forward — C to D (1), D to E (2). Shift = +2
  • Check A → C: A to B (1), B to C (2). Shift = +2 ✓
  • Check T → V: T to U (1), U to V (2). Shift = +2 ✓ Pattern confirmed.
  • Apply +2 to DOG: D→F, O→Q, G→I
Answer: FQI
D+2→F
O+2→Q
G+2→I
⚠️ Watch Out!

The "Starting at 1" Error: Never count the starting letter as 1! When working out A→C, say: "A to B (1), B to C (2) — that's +2." Students who count A as 1 will say +3, which gives wrong answers every time.

HARD EXAMPLE — SUN (VXQ) : FLY ( ? )
  • S→V: S to T(1), T to U(2), U to V(3). Shift = +3
  • U→X: U to V(1), V to W(2), W to X(3). Shift = +3 ✓
  • N→Q: N to O(1), O to P(2), P to Q(3). Shift = +3 ✓
  • Apply +3 to FLY: F+3=I, L+3=O, Y+3=B (wrap: Y→Z→A→B)
Answer: IOB

Directional Shifting (+ and −)

✓
🧒 Simple Explanation

The alphabet is like a number line. You can jump forward (towards Z) or backward (towards A). Forward jumps are + (plus) and backward jumps are − (minus). So from D, jumping +3 goes to G. From D, jumping −3 goes to A. Always check which direction the code goes!

📘 Full Explanation

In letter code questions, the shift can be positive (+n), meaning you move forward through the alphabet toward Z, or negative (−n), meaning you move backward toward A. To determine direction, check whether the code letter comes after (positive) or before (negative) the source letter in the alphabet. Always verify direction on at least two letters before applying it to the second word.

ZEBRA (BDFTC) : HORSE ( ? )
  • Z→B: forward past Z wraps to A, B — this is +2 (wraparound)
  • E→D: E comes AFTER D, so going backward. E to D = −1
  • B→F: forward. B to C(1) to D(2) to E(3) to F(4) = +4? No — B→D is +2. Let me recheck: B=2, D=4, gap=2. +2 ✓
  • Pattern: +2, −1, +2, −1, +2 (alternating)
  • Apply to HORSE: H+2=J, O−1=N, R+2=T, S−1=R, E+2=G
Answer: JNTRG
H+2→J
O−1→N
R+2→T
S−1→R
E+2→G
⚠️ Watch Out!

Direction Flip Error: The most common mistake is going forward when you should go backward. Always check: does the code letter come before or after the source letter in the alphabet? If the code letter is earlier (like B coming before E), the shift is negative (−).

HARD — FRAME (ISBND) : CLASH ( ? )
  • F→I: forward, +3
  • R→S: forward, +1
  • A→B: forward, +1
  • M→N: forward, +1
  • E→D: BACKWARD! −1. This breaks the pattern!
  • Pattern: +3, +1, +1, +1, −1 (no simple rule — must treat each position separately)
  • Apply to CLASH: C+3=F, L+1=M, A+1=B, S+1=T, H−1=G
Answer: FMBTG

The Wraparound Rule

✓
🧒 Simple Explanation

Think of the alphabet as a circle, not a straight line. When you reach Z and keep going forward, you arrive back at A. It's like a clock — after 12 comes 1 again! So if a letter is near Z and you add steps, just continue counting from A. If a letter is near A and you subtract steps, count backwards from Z.

📘 Full Explanation

The wraparound rule states that the alphabet is treated as a continuous loop (A–Z–A–Z…). When a positive shift takes you past Z, you re-enter at A and continue counting. When a negative shift takes you before A, you re-enter at Z. This is the most frequently failed sub-skill in GL papers because students try to count "the long way" or panic at the boundaries. The key is to use the alphabet's circular nature and count as few steps as possible.

WRAP: Y + 4 = ?
  • Y → Z (1 step forward, we've hit the end)
  • Z → A (2 steps, we wrap around to the beginning)
  • A → B (3 steps)
  • B → C (4 steps) ✓
Y + 4 = C
Tip: Y is the 25th letter. 25 + 4 = 29. 29 − 26 = 3. The 3rd letter is C. ✓
WRAP BACKWARD: B − 4 = ?
  • B → A (1 step back)
  • A → Z (2 steps, we wrap to end of alphabet)
  • Z → Y (3 steps)
  • Y → X (4 steps) ✓
B − 4 = X
Tip: B is the 2nd letter. 2 − 4 = −2. −2 + 26 = 24. The 24th letter is X. ✓
⚠️ Watch Out!

The Off-by-One Wraparound Error: The trickiest mistake — when counting Z→A→B, some students count Z as step 1. Wrong! Z is the starting point. A is step 1, B is step 2. So Y+2 = A (Y→Z is 1, Z→A is 2). Use the alphabet strip at the top of the page to avoid this error.

Zero Shift Recognition

✓
🧒 Simple Explanation

Sometimes a letter doesn't move at all — it stays exactly the same! This is a zero shift (or no shift). Don't panic if you see the same letter in both the word and the code. It's not a trick — it just means that position doesn't change. Look for it carefully, especially in the middle of words.

📘 Full Explanation

Zero shift occurs when a letter in the source word maps directly to the same letter in the code (shift value = 0). Students commonly panic and assume they've made an error when they see a letter unchanged, but it is a legitimate part of the pattern. Zero shifts often appear in alternating or position-based patterns (e.g., odd positions shift +2, even positions shift 0). Recognising zero shifts accurately is a mark-separator in harder GL papers.

ROBIN (RODIN) — spot the zero!
  • R→R: same letter — shift = 0
  • O→O: same letter — shift = 0
  • B→D: B to C(1) to D(2) = +2
  • I→I: same letter — shift = 0
  • N→N: same letter — shift = 0
Pattern: 0, 0, +2, 0, 0 — only the middle letter shifts!
⚠️ Watch Out!

The Panic Error: When you see the same letter appear in both the word and code, students often think they've made a mistake. Don't re-do your calculation! A zero shift is deliberate. Write "0" for that position and move on confidently.

Mixed & Alternating Shifts

✓
🧒 Simple Explanation

Sometimes letters in a word take turns jumping different amounts. Like odd letters might jump +2 and even letters jump −1. It's like a dance where every other person does a different move! You need to find the pattern — is it every other letter? Or does it repeat every three? Always check each position!

📘 Full Explanation

Alternating shifts occur when different positions in the word follow different shift rules, often in a repeating pattern (e.g., +2, −1, +2, −1 or +1, +2, +1, +2). Mixed shifts are less regular — each position has its own unique shift value. To identify the pattern: calculate the shift for every letter, write them out, and look for repetition. Never assume the first two letters define the full pattern without checking all positions.

BLEND (DKCOF) : STONE ( ? )
  • B→D: +2
  • L→K: L(12)→K(11) = −1
  • E→C: E(5)→C(3) = −2? No: E→D is −1, D→C is −2. So −2? Wait: E(5)→C(3)=−2. Hmm. Or is it +2? No, C comes before E. So −2.
  • N→O: N(14)→O(15) = +1
  • D→F: D(4)→F(6) = +2
  • Pattern: +2, −1, −2, +1, +2 — this is irregular, so treat each position independently
  • Apply position-by-position to STONE: S+2=U, T−1=S, O−2=M, N+1=O, E+2=G
Answer: USMOG
⚠️ Watch Out!

Assuming Two Letters Define the Whole Pattern: If the first two letters both shift +2, students assume ALL letters shift +2. Always check the third, fourth, and fifth letters before applying the pattern! In GL harder papers, the pattern often breaks on the last letter — that's the trap.

ALTERNATING: SUPER (RVTGQ) : CRANE ( ? )
  • S→R: −1
  • U→V: +1
  • P→T: +4? P(16)→T(20)=+4. Hmm. Or: S→R(−1), U→V(+1), P→T(−1)? P→T is forward... Let me check: P=16, T=20, that's +4. So pattern is irregular: −1,+1,+4,+2,−1.
  • Actually let's recalculate: S(19)→R(18)=−1, U(21)→V(22)=+1, P(16)→T(20)=+4, E(5)→G(7)=+2, R(18)→Q(17)=−1
  • Each position is independent. Apply to CRANE: C−1=B, R+1=S, A+4=E, N+2=P, E−1=D
Answer: BSEPD

Increasing / Decreasing Shifts

✓
🧒 Simple Explanation

Imagine a staircase: each step is one level higher than the last. If the first letter jumps 1 step, the second jumps 2, the third jumps 3 — the jumps keep growing! This is an increasing shift. Once you spot that the jumps are going up (or down), you can predict the next jump and solve the puzzle faster.

📘 Full Explanation

In an increasing shift pattern, the shift value grows by a fixed amount at each position (e.g., +1, +2, +3, +4, +5). A decreasing shift works in reverse. These patterns are the hardest GL variant because students must identify the sequence of shift values before applying them, not just a single shift. Always verify the progression on all source letters — never assume after seeing just two positions.

PLANE (QNCPJ) : TRUCK ( ? )
  • P→Q: P(16)→Q(17) = +1
  • L→N: L(12)→N(14) = +2
  • A→D: A(1)→D(4) = +3
  • N→R: N(14)→R(18) = +4
  • E→J: E(5)→J(10) = +5
  • Pattern confirmed: +1, +2, +3, +4, +5
  • Apply to TRUCK: T+1=U, R+2=T, U+3=X, C+4=G, K+5=P
Answer: UTXGP
T+1→U
R+2→T
U+3→X
C+4→G
K+5→P
⚠️ Watch Out!

Stopping After Two Letters: Students see +1, +2 and think "it must be alternating +1,+2,+1,+2" — but it's actually +1,+2,+3,+4,+5! Always calculate the shift for ALL letters before deciding on the pattern. Three data points confirm an increasing sequence.
