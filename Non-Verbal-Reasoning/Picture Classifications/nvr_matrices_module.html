What Is a Matrix Question?

✓
Simple Explanation

A matrix is like a grid of pictures — usually 2×2 or 3×3. Think of it as a table where shapes follow a pattern going across each row and down each column. One square is missing (usually the bottom-right). Your job is to work out what pattern the shapes follow, then pick the missing square.

It's like a puzzle where every row tells you a rule — and you have to use that rule to predict what comes next.

Full Explanation

Matrix questions present a grid (2×2 or 3×3) of figures with one cell missing. Figures follow consistent rules across rows and/or down columns. Rules may involve: attribute progression (size/count increases), alternating patterns, rotation (shapes turn by a set angle), translation (elements move position), combination (elements from two cells merge into a third), and dual independent rules (different rules govern different properties simultaneously).

⚡ The Priority Scanning System

When you see a matrix, scan these properties in this order:

1
Count — dots, sides, elements
2
Shape — what type of shape
3
Rotation — which way is it pointing?
4
Shading — filled, empty, striped?
Abandon Rule Fast: If your rule doesn't work for 2 rows, it is wrong — drop it immediately and try the next property.

Predict Before You Look: Before reading the answer options, mentally describe what the missing square should look like. Then find the option that matches your prediction.
2×2 vs 3×3 — Different Strategies
2×2 Grid
Usually involves a single transformation: one shape is rotated, reflected, or shaded differently. Look for what changes between left and right — apply the same change top and bottom.
3×3 Grid
Usually involves progression or dual rules. Check rows first (left→right pattern), then check columns (top→bottom pattern). At high level, the row rule and column rule may be different.

Attribute Progression

✓
Simple Explanation

Imagine stairs. Each step goes up by the same amount. In a matrix, a property — like the number of dots or the size of a shape — can go up (or down) by the same amount in every row or column. Count what changes and by how much — then continue the pattern.

Also watch for counting with reset: sometimes the count goes 1→2→3 then resets to 1→2→3 again. Don't assume it always keeps going up!

Full Explanation

Attribute progression rules involve a numerical property that changes by a fixed amount (the common difference) across each row or down each column. Properties that progress include: number of sides, number of dots/spots, number of internal lines, size, or position value. Counting with reset is a key variant: the sequence cycles (e.g. 1→2→3→1→2→3) rather than continuing linearly. Always check whether the pattern continues or resets.

Each row shows a grid with increasing dots. What goes in the missing square (bottom-right)?

R2C1
R2C2
R2C3
R3C1

Grid: outer shape changes by row; dot count increases across each row (+1)
  1. 1
    What changes across each row? Dot count: R1: 1→2→3, R2: 1→2→3, R3: 1→2→?. Pattern is +1 per column. Missing square needs 3 dots.
  2. 2
    What changes down each column? Outer shape: Row 1=plain dots, Row 2=square border, Row 3=circle border. Row 3 pattern → circle border.
  3. 3
    Combine both rules: Missing square = circle border + 3 dots. ✓
⚠️ Watch Out!

Counting with Reset trap: If you see 1→2→3 in row 1, you might assume row 2 continues with 4→5→6. But in many GL grids, each row RESETS to 1→2→3. Always check row 2 from the start — don't assume it continues from where row 1 left off.

📐 Worked Example 2 — Harder: +2 Progression with Column Reset

Row rule: sides increase by 2 (triangle→pentagon→heptagon). Column rule: size increases (small→medium→large). What fills the missing cell?

  1. 1
    Row 1: triangle(3)→pentagon(5)→heptagon(7). +2 sides each step.
  2. 2
    Row 2 starts again: triangle(3)→pentagon(5)→? = heptagon(7). NOT 9.
  3. 3
    Column 3: small heptagon → medium heptagon → large heptagon. That is the answer.
Key lesson: Row 2 resets the count. Students who think "the next shape has 9 sides" are applying a global linear rule that doesn't exist. Check each row independently.

Alternating Patterns

✓
Simple Explanation

Think of a light switch. On, off, on, off. An alternating pattern just switches back and forth between two things — it never "progresses" or gets bigger. In a matrix, a shape might go: Circle → Square → Circle → Square. Or shading: filled → empty → filled → empty. It's not going anywhere — it's just taking turns.

Full Explanation

Alternating patterns follow an A→B→A→B cycle rather than a linear progression. Common alternating properties: shape type (circle↔square), shading (filled↔empty), orientation (upright↔inverted), line style (solid↔dashed), and element presence (dot present↔absent). Key diagnostic: if position 1 = position 3 in a row, the pattern is alternating, not progressing.

📐 Worked Example — Alternating Shape Type

3×3 grid. Row 1: circle, square, circle. Row 2: square, circle, square. Row 3: circle, square, ?

  1. 1
    Row 1: circle→square→circle. Position 1 = position 3. This is alternating (A→B→A), not progressing.
  2. 2
    Row 2: square→circle→square. Same alternating rule, but starts on square this time.
  3. 3
    Row 3: circle→square→? The pattern is A→B→A, so position 3 = circle again.
  4. 4
    Column check: Column 3 has: circle (R1), square (R2), ? (R3). Alternating → circle. ✓ Both checks agree.
⚠️ Watch Out!

Don't confuse alternating with progression: Students often see circle→square and assume the next step must be something new (like triangle). But if the third cell matches the first cell, the pattern is alternating — it goes back, not forward. Always check whether position 1 = position 3 before assuming progression.

Rotation Rules

✓
Simple Explanation

Imagine spinning a clock hand. If it starts pointing up, after a quarter turn it points to the right. After another quarter turn, it points down. In matrix questions, a shape might rotate by the same amount each step. Work out how far it has turned — then turn it the same amount again.

Also remember: rotating (spinning) is different from reflecting (flipping in a mirror). An "L" shape rotated four times returns to the start. An "L" reflected looks backwards and can never be rotated back.

Full Explanation

Rotation rules involve shapes turning by a fixed angle (45°, 90°, 180°) across each row or down each column. Key distinctions: rotation vs reflection (asymmetric shapes can be reflected but no rotation achieves the mirror image); element rotation inside a shape (a dot inside a square moves clockwise/anticlockwise rather than the whole shape rotating); progressive rotation (45°→90°→135° each step). Always check whether an apparently rotated shape is actually a reflection.

📐 Worked Example — 90° Clockwise Rotation

An arrow points up in cell (1,1). It rotates 90° clockwise each step. Where does it point in cell (2,3)?

  1. 1
    Start: arrow points UP (12 o'clock).
  2. 2
    +90° clockwise = points RIGHT (3 o'clock). This is cell (1,2).
  3. 3
    +90° clockwise = points DOWN (6 o'clock). This is cell (1,3).
  4. 4
    Row 2 continues: +90° = points LEFT (9 o'clock). Cell (2,1).
  5. 5
    +90° = points UP again. Cell (2,2). +90° = points RIGHT. Cell (2,3).
  6. 6
    Answer: arrow points RIGHT in cell (2,3).
⚠️ Watch Out!

Rotation vs Reflection trap: If a shape is asymmetric (like an F, L, or R), a reflected version looks like a rotation but isn't. Test: trace the shape, physically rotate your paper — if you can't match the option by rotating, it's a reflection and a different rule applies. At GL level, one option in the answer choices is always the reflection of the correct rotation.

Translation & Cyclic Movement

✓
Simple Explanation

Translation means moving without rotating or changing. Imagine a ball that slides from the left side of a box to the right side. It doesn't spin — it just moves. In matrix questions, a dot or element might slide across, up, or down — or it might move in a circle (clockwise or anticlockwise) inside the shape. Track where it starts, and figure out which direction and how far it moves each step.

Full Explanation

Translational rules involve elements moving position without changing shape or orientation. Two subtypes: linear translation (element moves left/right or up/down by a fixed distance) and cyclic movement (element moves around a fixed loop: top→right→bottom→left→top for a square, or clockwise around a circle). Cyclic movement is very common in GL and easy to miss if you only check "what the shape looks like" rather than "where the element is."

📐 Worked Example — Cyclic Dot Movement

A square has a dot. The dot moves clockwise: top→right→bottom→left. Matrix has this sequence continuing across cells. Cell 1: dot at top. Cell 2: dot at right. Cell 3: dot at bottom. Cell 4: dot at ?

  1. 1
    Identify the cycle: top→right→bottom→left (4 positions in a clockwise loop).
  2. 2
    Map positions: Cell 1=top, Cell 2=right, Cell 3=bottom, Cell 4=?
  3. 3
    After "bottom" comes "left" in the clockwise cycle. Cell 4 = dot at left.
  4. 4
    Cell 5 would return to top. The cycle repeats every 4 steps.
⚠️ Watch Out!

"Near the edge" ≠ "at the edge": In translation questions, being precise matters. A dot "near the top" is different from a dot "at the top". Similarly, don't confuse "moving right" with "rotating" — a shape that slides right doesn't change its orientation at all. If the shape looks exactly the same but is in a different position, that's translation, not rotation.

Combination Rules

✓
Simple Explanation

Imagine you have two stamps. You press stamp A on paper (you see shape A). You press stamp B on paper (you see shape B). Now you press both stamps together on the same paper — you see both shapes overlapping. In a combination matrix, the third square is made by combining (overlapping) the first two.

Sometimes it works differently: shapes that appear in BOTH the first two squares cancel out (disappear) in the third square. This is called XOR logic.

Full Explanation

Combination rules use the first two cells in a row to produce the third. Two main variants: Union (OR) — the third cell contains everything from both cells; XOR (Exclusive OR) — the third cell contains only elements that appear in exactly ONE of the first two cells (elements appearing in BOTH cancel out). A third variant: selective combination — only some properties combine (e.g. shapes merge but shading doesn't). Always check whether it's union or XOR by looking at overlapping elements.

📐 Worked Example — XOR Combination

Row 1: Cell A has (circle + dot). Cell B has (circle + triangle). Cell C = ?

  1. 1
    List elements in A: circle ✓, dot ✓.
  2. 2
    List elements in B: circle ✓, triangle ✓.
  3. 3
    Find what appears in BOTH: circle appears in both A and B.
  4. 4
    XOR rule: elements in BOTH cancel. Elements in ONLY ONE survive.
  5. 5
    Survivors: dot (only in A) + triangle (only in B). Circle cancels out.
  6. 6
    Cell C = dot + triangle (no circle).
⚠️ Watch Out!

Union vs XOR confusion: The most common mistake is using the wrong combination rule. Always verify your rule by checking Row 2: if both union and XOR seem possible in Row 1, the Row 2 result will tell you which is correct. If an element appears in BOTH cells 1 and 2 of row 2 and ALSO appears in cell 3 of row 2 — it's union. If it disappears in cell 3 — it's XOR.

Dual & Multi-Variable Rules

✓
Simple Explanation

Imagine a game where two things change at once — the colour of a ball changes AND its size changes — by different rules. This is what "dual rules" means in matrix questions. The shape might follow one rule across the row. The shading might follow a completely different rule down the column. You have to find BOTH rules and use BOTH to get the answer.

The hardest version: the row rule and the column rule are different. Using only one will give you a wrong answer that almost fits.

Full Explanation

Dual-rule grids have two independent rules operating simultaneously: one rule governs one property (e.g. shape type changes by row), and a completely separate rule governs another property (e.g. shading changes by column). At the highest GL level, the row rule and the column rule may be different rules entirely — for example, rows follow an alternating pattern while columns follow a +1 progression. The correct answer must satisfy BOTH rules simultaneously.

📐 Worked Example — Row ≠ Column Rule

3×3 grid. Row rule: shape alternates circle↔square. Column rule: dot count increases (+1 per row). Find R3C3.

  1. 1
    Row rule: Odd rows = circle, even rows = square. Row 3 is odd → circle.
  2. 2
    Column rule: Column 3 dot count by row: R1=1 dot, R2=2 dots, R3=3 dots. → 3 dots.
  3. 3
    Combine: R3C3 = circle with 3 dots.
  4. 4
    Trap check: Wrong answer "square with 3 dots" satisfies the column rule but fails the row rule. Wrong answer "circle with 2 dots" satisfies the row rule but fails the column rule. Only "circle with 3 dots" satisfies BOTH.
Rule Interference check: After you find your answer using the row rule, check it against the column rule. If your answer doesn't fit the column, you've only solved half the problem.
⚠️ Watch Out!

The "Almost Works" option: At GL level, one wrong answer option satisfies the row rule perfectly but violates the column rule. Another wrong option satisfies the column rule but not the row. Students who only check one direction will pick these traps. Always verify your answer against BOTH rows AND columns.

Common Traps & Misconceptions

✓
⚠️ Trap 1: The Fake Pattern

The first row appears to show a clear rule. The second row breaks it — revealing the real rule was different. Never finalise your rule after checking only ONE row. Always verify it works in at least two rows before trusting it.

⚠️ Trap 2: The "Almost Works" Answer

One wrong option fits the row rule perfectly but fails the column rule. Another fits the column but not the row. Students who check only one direction get confidently wrong answers. Always check BOTH directions.

⚠️ Trap 3: Single Variable Bias

You notice the shape rotates — and lock onto that as "the rule". But shading is also changing by a different rule. Because you fixed on rotation, you miss the shading. Always scan ALL four properties (Count, Shape, Rotation, Shading) before deciding which one is the rule.

⚠️ Trap 4: Overcomplication

You invent a complex, multi-step rule that fits cells 1 and 2 but has exceptions. Meanwhile the real rule is simple (+1 dot per column). If your rule requires more than one sentence to explain, try again with simpler properties first.

⚠️ Trap 5: Diagonal Distraction

Sometimes a pattern appears along the diagonal (top-left → middle → bottom-right). GL matrices almost never use diagonal rules — rows and columns are always the intended logic. If you think you see a diagonal pattern, check rows and columns first.
