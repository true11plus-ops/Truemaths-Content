What Are Letter Codes?

✓
🟡 Simple Explanation (Age 9–10 Friendly)

Imagine you're a spy, and you have a secret code for describing shapes. Instead of writing "big black circle", you write two letters like BX. One letter means the shape, one letter means the colour. The shapes all follow the same rules — you just have to figure out what each letter stands for by comparing the shapes you're given.


Your job: look at the shapes, work out what each letter means, then use those rules to work out the code for a new shape — the TARGET.

📘 Full Explanation

In NVR Letter Codes questions, you are presented with a set of shapes, each assigned a code made up of letters (typically 2–3 letters). Each letter in the code represents exactly one visual attribute of the shape (e.g. shape type, fill/shading, size, number of sides, orientation, number of internal markings). You must:

  1. Deduce what each letter encodes by comparing shapes with shared letters
  2. Apply that decoded mapping to a target shape
  3. Select or write the correct code for that target shape

Key GL Assessment facts: Each letter maps to exactly one attribute value. The same letter never represents two different values. Some attributes may not be coded at all ("silent attributes"). Letter position (top/bottom or first/second) usually tracks consistently — but not always on harder questions.

Single-Letter Codes

✓
🟡 Simple Explanation

Think of it like a nickname. Every shape has one secret nickname (one letter). All circles share the same letter. All squares share the same letter. Your job is to figure out which nickname belongs to which shape.


How to find the nickname: Look for two shapes that both have the same letter. Whatever they have in common — that's what the letter means.

📘 Full Explanation

In single-letter code questions, each shape is given a one-letter code that encodes a single attribute. You identify the attribute by finding pairs of shapes that share the same letter and isolating the feature they share. Since there is only one attribute, the mapping is direct: letter → one specific visual property value.

Two-Letter Codes

✓
🟡 Simple Explanation

Now instead of one secret nickname, each shape has TWO. The first letter is about one thing (like the shape), the second letter is about something else (like the colour). It's like a spy ID card with two parts.


To crack the code: find two shapes that share their first letter. Whatever they have in common — that's what the first letter means. Then find two shapes that share their second letter — that tells you what the second letter means.

📘 Full Explanation

In two-letter code questions, each letter independently encodes one attribute. The first letter typically encodes one feature (e.g. shape type) and the second letter encodes another (e.g. fill). You isolate each letter's meaning by finding pairs of shapes that share that letter and identifying the common attribute.

The Core Method
  • Find two shapes sharing the same first letter → that feature is constant → first letter encodes it
  • Find two shapes sharing the same second letter → that feature is constant → second letter encodes it
  • Build your full mapping table
  • Apply to target shape

AX and AY both start with A. What do they share? Both are circles. So A = circle. BX starts with B → B = square.

2
Decode second letter

AX and BX both end in X. What do they share? Both are black. So X = black. AY ends in Y → Y = white.

3
Apply to target

White Square: square = B, white = Y → BY.

✅ Answer: BY
⚠️ Watch Out!

Don't just guess the letter position. A common mistake is assuming "first letter = shape, second letter = fill" in every question. GL sometimes reverses this or encodes size, orientation, or number of sides in either position. Always verify which feature each letter encodes by finding pairs — never assume.

Three-Letter Codes

✓
🟡 Simple Explanation

Now there are THREE letters, each with a different job. Think of it like a three-word address: house number, street name, and postcode. Each part tells you something different. More letters = more features are coded, but the same method works: find shapes sharing each letter and spot the common feature.

📘 Full Explanation

Three-letter codes encode three independent attributes simultaneously. The decoding method is the same: isolate each letter by finding pairs that share it. However, with three variables, the risk of "false sharing" increases — two shapes may share a letter AND share an irrelevant feature coincidentally. Always verify your rule using a third shape when possible. Build an elimination table to track all three letters systematically.

4
Resolve P

Since M=circle, and M does NOT appear in KOP/NOP shapes, P = non-circle (square/triangle). Actually in GL format, shape type IS encoded: M=circle, P=polygon (square or triangle). For the target "triangle", we check: KOP has square, NOP has triangle — both have P. P cannot encode a specific polygon. So in this question, shape type (square vs triangle) is the silent attribute within P-coded shapes. P = polygon (non-circle). Target = triangle = polygon.

5
Apply to target

Large, black, triangle: Large=K, Black=L, triangle=polygon=P → KLP

✅ Answer: KLP
⚠️ Watch Out!

With 3 letters, it's easy to get one wrong and still feel confident. Always check all three letters independently. A common error is correctly decoding the first two letters and then guessing the third. Use the elimination table for every 3-letter question.

Advanced Traps & Misconceptions

✓

Trap 1: Silent Attributes — Not Everything is Coded

🔇 Silent Attribute Alert

A SILENT ATTRIBUTE is a feature you can see in the shapes, but it is NOT coded by any letter. Students waste time trying to assign it a letter. The rule: if a feature changes but NO LETTER tracks it consistently, it is silent.

The "Everything Must Be Coded" Fallacy

Just because you can see 4 different features does not mean all 4 are coded. GL often includes 1 or 2 silent attributes to distract you. Check every feature carefully before assuming it has a letter.

Trap 2: Visual Dominance Bias — The Obvious is Often Wrong

Visual Dominance Bias

The most visually striking feature (bold shape, strong colour, unusual pattern) pulls your attention first. GL examiners know this and deliberately make that feature a silent attribute. Always check ALL features systematically — don't just code the first thing you notice.

● Mastery — Visual Dominance Trap

Trap 3: Decoy Correlation — Two Features Change Together

Decoy Correlation

Sometimes two features always change at the same time (e.g. size always changes with colour). This makes it impossible to tell which one is coded. In GL exams, one of them is the intended coded feature — and the other is silent. You must use all available shapes to deduce which is which, or use back-solving from the answer choices.

Back-Solving: Plan B Strategy

✓
🟡 Simple Explanation

Sometimes you cannot work out what a letter means from the shapes alone. That is when you do it backwards: look at the answer choices, pick one, and test if it fits all the rules. If it contradicts any shape's code, cross it out. Keep doing this until only one answer survives.

📘 Full Explanation

Back-solving (also called "working from options" or "test-and-eliminate") is the strategy used when direct decoding is impossible — for example, when all codes in the set are unique (no shared letters between shapes) or when only partial mapping is possible. You test each answer option against the known codes, checking for contradictions. Any option that contradicts a known rule is eliminated. The surviving option is the answer.

🛡️ Plan B: When Direct Decoding Fails

Use back-solving when: (1) No two shapes share a letter. (2) You have decoded only 1 or 2 letters and cannot isolate the third. (3) You are running short on time and need a fast elimination route.

🟢 Worked Example — Back-Solving
Large, black, circle
→
ABC
Small, white, square
→
DEF
Large, white, triangle
→
AGF

Target: Small, black, triangle

1
Decode what you can

ABC and AGF share A → both large → A=large. DEF has D for small → D=small. ABC has B for black+circle, AGF has G for white+triangle — G and B differ in colour and shape, hard to isolate from one example each.

2
Partial decode

A=large, D=small. Second letter: B (black+circle) vs G (white+triangle) vs E (white+square) — B is the only black one → B=black. Third letter: C=circle, F=square/triangle (both DEF and AGF end in F — both non-circle shapes) → F=non-circle shape, C=circle.

3
Back-solve the target

Small+black+triangle: small=D, black=B, triangle=F (non-circle). → DBF. Check against options to verify no contradiction.

✅ Answer: DBF
⚠️ Watch Out!

Back-solving is a last resort, not a first resort. Always try direct decoding first. Back-solving takes longer and is more prone to errors if you misread the answer options. Use it only when you're stuck after 30 seconds of direct decoding.
